# 프로젝트 규칙

- 프로젝트: Garmin Training Agent.
- 소통 및 사용자 작성 문서는 한국어를 기본으로 한다.
- 제품 범위, Garmin 연동, 기술 스택, 배포 환경은 미정이다. 요구사항 단계에서 결정한다.
- 기본 구조 구성은 제품 개발 승인이나 운영 준비 완료를 의미하지 않는다.
- 프로젝트 공통 지침은 루트 AGENTS.md를 따른다.
- 실제 자격증명과 건강/활동 데이터는 커밋하지 않는다. 테스트는 합성 데이터를 기본으로 한다.
- 공식 런타임을 직접 수정하지 말고 프로젝트 규칙과 지식 문서로 확장한다.
