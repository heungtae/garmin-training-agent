## Assumptions

검증되지 않은 외부 서비스 지원을 사실로 가정하지 않는다. 설계 계속 가능이라는 판단은 외부 기능이 확인되지 않아도 제한·대체 경로를 명시할 수 있다는 조건부 판단이다. 실제 경로가 P0를 충족하지 못하면 범위 재결정이 필요하다.

## 후속 확인 책임

요청자는 계정 접근 조건과 제품 정책을 결정한다. 설계 작업에서는 검증 항목·기대 결과·실패 대안을 명시하고, 실제 실행 증거는 해당 시험이 수행된 뒤에만 상태에 반영한다. 현재 실제 외부 API 호출이나 게시 시험 결과는 없다.
