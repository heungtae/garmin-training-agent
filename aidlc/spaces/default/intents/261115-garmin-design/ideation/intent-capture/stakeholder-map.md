# Garmin Training Agent 이해관계자

## Stakeholders

| 대상 | 관심사 및 역할 | Source |
|---|---|---|
| 개인 최종 사용자 | 기록 정확성, 계획 통제, 개인정보 보호, 연동 상태 확인 | [Q4] |
| 현재 요청자 | 제품 범위와 우선순위의 최종 결정 | [Q5] |
| 외부 서비스 | 기능·권한의 제약을 제공하는 의존 대상이며 사람 승인권자로 취급하지 않음 | [Q4] |

## Decision Makers and Influencers

현재 요청자가 범위와 우선순위를 결정하며 별도 승인권자는 없다. 추가 사람 이해관계자도 없다. [Q4] [Q5]
