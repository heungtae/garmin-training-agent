### Q3 판단 근거

아래 공급자 비교와 최초 선택은 변경 전 검토 이력이다. 현재 설계·설치·검증 대상에서 Ollama는 제외하며, 원격 OpenAI API와 대체 제공자 미정인 로컬/사설 연결 유형을 구분한다.

- [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)은 메시지 기반 요청을 제공하며 모델별 매개변수 지원이 다를 수 있다고 명시한다.
- [Ollama OpenAI 호환](https://docs.ollama.com/api/openai-compatibility)은 OpenAI API 일부 호환과 로컬 서버 사용을 설명한다. 로컬 서버를 통한 클라우드 모델 사용도 별도 설명하므로 localhost 주소만으로 실제 로컬 추론을 증명하지 않는다.
- [OpenRouter API 개요](https://openrouter.ai/docs/api_reference/overview)는 OpenAI 유사 요청/응답과 모델·제공자 간 정규화를 설명하며 API 차이와 모델별 기능 확인이 필요하다.
- 이 질문은 초기 **검증 대상** 선택이다. 공급자를 영구 고정하거나 실제 호출·설치·결제를 시작하지 않는다. 구체 모델·로컬 최소 사양·응답 품질/지연·유료 사용 한도와 비용 조건은 미검증이며 선정/실증 조건으로 기록한다. 공통 계약만 맞으면 모두 동작한다고 가정하지 않는다.
