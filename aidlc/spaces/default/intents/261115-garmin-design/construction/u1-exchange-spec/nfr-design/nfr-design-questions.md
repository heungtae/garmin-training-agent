## 추가 질문 분석

추가 사용자 정책 선택이 필요한 일반 질문은 없다. U1은 실행 서비스가 아닌 공통 교환 명세이므로 승인한 상세 NFR 22개와 6개 기술 결정에 대해 검증 경계·오류/보류·필수 합성 사례·증거 인계를 구체화한다. 앱/검증기 전체 구현이나 실제 원 정책/승인 발급·외부 실행은 소비자 책임이다. 다른 단위의 실행기/DB/자체 fixture를 U1 자체 검사 필수 의존으로 추가하지 않는다.

별도 서버 성능·가용성·확장·관측·논리 인프라 산출물을 만들지 않는다. 템플릿의 예시 Redis·CDN·다중 AZ·circuit breaker 수치/비율을 U1 요구로 승격하지 않는다. 기존 앱 기술·규칙/명세의 변경은 이 단계에 포함하지 않는다.

## 남는 위험과 검증 경계

ConsumerBinding에 소비자 구현/워크플로 개정 식별이 부족한 상류 승인 위험을 해결됐다고 바꾸지 않는다. 검사 보고의 사용 가능한 도구/프로필·입력·명세 고정과 한계 고지는 개정별 완전한 재현성 또는 기존 모델 보완을 뜻하지 않는다. 이전 기능/NFR 요구사항 문서를 이 단계에서 수정하지 않는다.

원 정책 신뢰/현재성·인간 의도/정확한 승인·안전 적격성, 실제 ChatGPT 웹/모바일 지원·Drive/GitHub/Calendar 효과/C08 신뢰·Garmin 상세 계약·원격 OpenAI 모델/비용·로컬/사설 대체 제공자/처리 위치/하드웨어·정밀 Decimal/tzdb·유한 실제 도구 한도는 미해소로 유지한다. Ollama 제외와 미해소 기능 활성화 보류를 유지한다.

합성 자료만 사용한다. 0건/전수 기대 일치는 고정 필수 검사 집합의 합격 조건이며 모든 자연어의 민감성 판별·실제 권한/승인/의료 안전/외부 성공 보장이 아니다. 검증은 문서·ID/링크/표/추적성·규칙/사례 연결 정합과 실제 실행/외부 인수를 구별한다.

## Consolidated Summary Confirmation

- U1의 승인된 상세 요구사항 22개를 검증 순서·차단 조건·필수 합성 사례·안전한 오류/증거 인계와 연결하는 security-design.md·traceability.json을 작성한다.
- 고정 registry/버전·등록 참조·전체 JSON JCS SHA-256을 기준으로 입력/구조·무결성·값/시간/완전성·정책/승인·실제 외부 권위의 검사 단계를 분리한다. 외부 자료는 검사 기준이나 권한을 바꾸지 못한다.
- 모든 실제 경로의 정확한 공유 집합·withheld/파생 유출 방지·정확한 전체 계획/행위와 새 내용 새 승인·기간/DST·부분/미확인 결과·생산자/세션별 상태를 기존 계약대로 유지한다.
- 출력/진단은 비밀·금지 자료를 제외하고, 고정 사례의 기대/관찰·수행 범위·도구 프로필·한계를 기록한다. 소비자 개정 식별이 부족한 기존 ConsumerBinding 위험은 미해결로 남긴다.
- U1에 앱/서버/DB/클라우드·새 성능/가용성 SLA나 실행기를 추가하지 않는다. wire/기능 모델을 몰래 변경하지 않고 실제 라이브러리/자원/비밀 보호와 외부 권한/효과 검증은 해당 소비자에게 연결한다.
