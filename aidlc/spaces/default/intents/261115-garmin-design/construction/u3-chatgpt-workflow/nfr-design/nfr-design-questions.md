## 추가 질문 분석

새 사용자 판단이 필요한 특별한 결정이나 추가 일반 질문은 없다. 승인된 상세 NFR 25개·기술 결정 9개·U3-01~36 및 B3-01~11의 입력/기대값을 유지하면서 구체 검증 순서·결과·보류/복구·소유자와 증거 인계를 설계한다. 원 정책 현재성·독립 승인·실제 도구 적격성/안전을 해소한 것으로 추정하지 않는다.

## 설계 기준과 구체화할 해법

| 축 | 입력·처리·출력/차단과 책임 |
|---|---|
| 환경 적격성 | 계정/클라이언트/웹·모바일/도구·관측 시점별 읽기·JSON 생성·쓰기·전체 재읽기·지속 조회 및 실제 유한 시간/시도/bytes/깊이/호출 프로필을 확인한다. 해당 프로필을 검증/강제할 수 없으면 관련 외부 요청을 만들지 않고 지원 미검증/보류와 필요한 증거를 안내한다. 단순 대화 지시만으로 도구의 강제력을 입증했다고 주장하지 않는다 |
| 정책·불신 입력 | 매 신규 요청 직전에 원 정책/주체/서비스·목적/대상·실제 권한/철회를 확인하고 모든 실제 ANALYSIS 경로의 정확한 필드 집합·최소 묶음·withheld/파생 유출을 대조한다. payload/문서/모델/profileId/오류 조치는 검사 기준·권한·명령이 될 수 없다. 현재성/범위/권한 불명은 외부 읽기/쓰기 보류 |
| 결정적인 내용 검증 | 유한 엄격 UTF-8/중복키/단일객체/고정 registry·Schema·전체 JCS SHA-256·불투명 ID/계보/분할 완전성/시간·단위 검사를 구분한다. 모델이 계산했다고 말한 hash를 검증된 digest로 쓰지 않는다. 실제 허용된 결정적 검증 도구/결과를 적격화하지 못하면 완전 검증/전달 성공을 자칭하지 않는다. U2 전용 구현/DB·PC 실행 권한에 의존하지 않는다 |
| 근거·완전 계획·안전 한계 | 목표 개정과 확인 입력/실제로 읽은 기간·원천/전달 완전성·0/미수집/추정/withheld를 구별한다. 전체 C05/세션/휴식·시각/단위·설명 정합을 검사하며 일부 오류는 전체 보류다. 자료 부족·충돌·큰 양/강도 변화는 비진단/불확실성·확인/조정 후보로 안내하고 안전 근거 미해소를 자동 해제하지 않는다 |
| 승인 의사·행위 결합 | 정확한 C05/C07 전체와 policy/timingPolicy·사용자/행위·digest/원 의사를 연결한다. C05는 PROPOSAL, C06은 불신 선언이며 근거 미확보는 내부 미해소다. 내용 변경은 새 버전/새 승인, REPLACE는 새 게시/처분의 두 범위를 각각 유지한다. 독립 ApprovalProof/현재 게시 적격성은 U2가 소유한다 |
| Drive 전달과 실제 STORE | 직접/허용 수동 모두 동일 정책/지원·내용/승인 조건, 같은 원 의도·고정 대상·버전별 전체 JSON을 사용한다. metadata-before→전체 blob 재읽기·엄격/내용 대조→metadata-after를 실제 확인한 자료별 결과만 기록한다. 성공 응답/fileId/업로드 보고만으로 SUCCESS를 만들지 않는다. 다중 파일 원자성은 가정하지 않는다 |
| 중단·동시 변경·미확인 복구 | 같은 목표/작성 개정·digest/workId·원 의도·마지막 완료·성공 부분을 보존한다. 복원 불가/현재성 불명은 새 효과 보류, 쓰기 미확인은 원격 실제 상태부터 대조한다. 내용/계보 변경은 충돌/새 승인으로 돌아가고 영구 오류는 조치 전 반복하지 않는다. 실제 프로필의 유한 한도/공급자 대기·기간 예산을 재개로 초기화하지 않는다 |
| 독립 결과·안전한 안내 | U3 STORE와 U2 RECEIVE/VALIDATE/EVALUATE/CALENDAR의 생산자/대상·버전/digest·시각/세션을 분리한다. C08 위치/권한/생산자/최신성 미확인은 인용도 미확인이다. 부분 성공/원 요청 세션·실패/마지막 성공과 한국어 조치를 표시하고 비밀·금지 자료·음성 표식 원문을 기록/echo하지 않는다 |

## 선택 범위와 미해소 조건

- U3에 앱/서버/DB/클라우드/PC 직접 호출·추가 사용자 승인 절차를 새로 만들지 않는다. U2의 systemd/SQLite/암호화 자격자료·성능/시간·bytes/깊이/큐 프로필을 U3 플랫폼의 지원/보장으로 전용하지 않는다.
- 기존 Markdown/UTF-8 JSON·고정 Draft2020-12 registry·전체 RFC8785 JCS/SHA-256과 시간/수치 의미를 유지한다. 검증 도구 이름/버전·실제 도구 강제력은 적격 프로필의 증거가 있어야 하며 미선정/미검증은 외부 요청 차단이다. 임의 구현/서비스를 설치하지 않는다.
- 검증된 실제 도구 경로가 확보되기 전에는 대화 흐름/검사 명세·합성 설계 기대값만 정의한다. ChatGPT 연결 도구가 이미 신뢰된 정책/전체 내용/승인을 검사한다고 주장하지 않는다. 지원 미확인 경로를 새 PC/서버 권한으로 우회하지 않는다.
- 기존 U3 강도 참조 BR3.5/BR3.6 불일치, ConsumerBinding의 소비자 개정 식별 부족, U2의 ChatGPT serviceName/연결 의미/반복 소수 정밀도 등 이미 승인된 한계는 유지하고 이전 모델/계약을 몰래 수정하지 않는다.
- 실제 C04 신뢰/철회·C06 인간 의도/현재성·안전·ChatGPT 환경별 지원·Drive 지속 저장/동시성·C08 신뢰·Garmin 상세 계약·원격 OpenAI 모델/비용·로컬/사설 제공자/처리 위치/하드웨어·Decimal/tzdb 적격성은 미해소다. Ollama 제외와 관련 실제 기능 보류를 유지한다.
- 새로운 비용/외부 실행·공유 범위/정책 변경·제품 기능 확대가 필요하면 사용자에게 특별 결정으로 확인한다. 현재 설계에는 그런 새 결정을 추가하지 않는다. 실제 데이터/비밀은 사용하지 않고 코드/설치/계정 호출/결제/커밋을 수행하지 않는다.

위 기준으로 후속 ARTIFACT-ONLY 작성을 진행한다. 추가 질문이 없으며 이번 작업에서 요약 확인은 비활성화되어 별도 확인 항목을 만들지 않는다.

## 2026-11-22 현재 입력 보충

기존 확인 입력은 보존한다. 이번 동기화는 개정 기능 설계·상세 요구사항·공유 계약을 적용하며 위 과거 미해소 기술/모델 설명 중 아래 항목은 현재 입력으로 대체한다. 새로운 사용자 응답·승인이나 실증을 생성하지 않는다.

- Intensity 엔티티 참조는 BR3.6으로 정정되었고 안전 경고 BR3.5와 구별된다. 과거 참조 불일치를 현재 미해소 위험으로 유지하지 않는다.
- GTA-NUMERIC-1은 정확 합계/유리수 중간 계산·최종6자리 HALF_EVEN·정규형 정확 대조·범위/오류/근거 규칙을 확정했다. NUM-01~16 및 computed 근거 변형이 현재 부합 입력이며 실제 도구 계산 적격성은 미검증이다.
- C04의 chatgpt 서비스·ANALYSIS/PLAN_STORAGE 목적별 원 동의 표현은 존재한다. 실제 원 정책 신뢰/현재성/철회·계정/연결 대응과 ConsumerBinding 소비자 개정 식별 한계는 별도 미해소다.
- 현재 사례는 U3-01~39다. U3-PRE-01~03의 도구/검사 위치·정책/한도/복구, 독립 발급/검증, 적격 안전 근거의 기록과 증명 절차는 security-design.md에 구체화한다. 실제 도구/발급자/안전 프로필은 미선정이며 모두 구현 선행조건이다. 합성 결과·차단 설계만으로 P0 전면 구현 준비 완료를 주장하지 않는다.
