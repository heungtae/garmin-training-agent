## 실행 예산과 종료 정리

[성능 요구사항](performance-requirements.md)의 NFR8.5~NFR8.6과 위 영속 예산을 함께 적용한다. 연결 10초/일반 전체 30초/LLM 전체 120초·최초 포함 3회는 각 실행 정리 포함 600초를 늘리지 않는다. 읽기/쓰기/메타데이터/대조/재시도/LLM의 **모든 실제 전송**을 차감하며 시작 전 영속 예약 실패는 전송 차단이다. 프로세스 종료나 요청 타임아웃은 원격 취소·미전송·비용 없음의 증거가 아니다. 남은 시간과 종료 정리 여유를 확보할 수 없으면 새 요청을 보내지 않고 미완료로 남긴다. 구체 정리/저장 보장 수단은 후속 설계에서 선정한다.

## 복구 범위와 활성화 차단

PC 종료/절전/오프라인 뒤에는 마지막 확정 지점과 pending을 재검사한다. 실제 공급자/모델의 쿼터·가격·권한/지원·대조 수단을 확인하기 전 Q3 수치를 운영 기본값으로 활성화하지 않는다. Garmin P05 상세 계약, 승인/정책 현재성·안전·외부 프로필·수치 정밀도·tzdb 적격성은 이 단계에서 해소하지 않았다. 독립 합성 시험에는 U1 고정 규범과 U2 자체 대역만 필요하며 형제 construction 구현/DB/시험을 필수 의존으로 두지 않는다.

디스크 가득 참/읽기 전용·통제 강제 종료의 확정 자료 보존 목표는 실제 디스크 손실/손상 복구나 외부 사본 삭제/휴지통 복원의 성공을 보장하지 않는다. 자동 백업은 새 기능으로 도입하지 않는다. 실제 제품의 장애/재시작·대조·중복/권한/수치/시간 시험은 모두 미실행이다.
