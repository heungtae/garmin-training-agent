## 확정하지 않은 값과 설계 인계

DB/비밀 보호/예약 수단·구체 라이브러리 이름/버전·유한 입력/출력 바이트·깊이·지수 백오프/지터·정리 여유·계측 수단은 NFR Design에서 공식 문서·대안·검증 계획을 근거로 선정한다. 위 대안은 제품 추천/지원 확정이 아닌 평가 축이다. 새로운 기술을 확정하지 않았으므로 공개 웹/API/계정 호출을 이 단계의 검증으로 주장하지 않는다. 실제 운영 프로필은 공급자 쿼터·정책/가격·사용 조건·권한/동의·기간별 호출/비용 예산을 검증한 뒤 활성화하며 Q1~Q3 수치만 복사해 활성화하지 않는다.

기준 환경 Ubuntu 24.04·2코어·4 GiB·SSD와 10,000활동/300세션은 시험 조건이다. 실제 설치 최소 사양·로컬/사설 추론 서버의 지원 사양이 아니다. 보존 기간은 첫 설정의 사용자 선택이며 미설정은 자동 삭제 없음이다. 예산 상한/마감 자체는 아직 지정되지 않았고 유료 사용 조건은 사용 전에 확인한다.

| 기존 위험 | 이 단계에서 유지하는 한계 | 후속 확인·차단 |
|---|---|---|
| ServiceConnection.serviceName에 chatgpt 없음 | 필수 ChatGPT 실제 경로 grant를 기존 연결 모델로 어떻게 묶는지 미해소; enum 추가 안 함 | 기능 모델 담당/NFR Design이 신뢰된 경로 바인딩 확인; NFR3.1 부합 입증 전 해당 경로 전송 보류 |
| RuntimeConfiguration.connectionIds의 의미 | 모든 연결 참조가 분석 게시 활성 대상인지, 계획 전달용 필수 연결과 어떻게 구별하는지 불명; 활성 대상 해석 추가 안 함 | 기능 모델 담당이 기존 요구/정책과 정합한 바인딩 확인; 연결 존재만으로 게시 활성·권한/동의 추정 금지 |

## 검증 한계

문서의 연결/ID/UTF-8/표·정적 정합성과 공식 traceability 검증만 수행한다. Rust 코드·설치/예약/로그아웃/DB/비밀/복구·성능·실제 API 호출·승인/안전/정책 현재성·LLM/비용·수치/tzdb 적격은 미실행이다. 기술 결정 문서 생성은 관련 프로필 구현/실제 지원/제품 인수를 완료하지 않는다.
