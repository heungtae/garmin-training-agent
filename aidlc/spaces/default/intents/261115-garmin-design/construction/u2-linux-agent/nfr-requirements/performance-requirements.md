## 기준 환경과 측정 경계

Ubuntu 24.04·CPU 2코어·RAM 4 GiB·SSD, 합성 운동 10,000건·계획 세션 300개를 고정한다. 실제 최소 사양·구매 권장·자료량 상한이나 지원 실적이 아니다. 고정 입력/설정 digest, 빌드 식별자, 명세/검사기·도구 버전, CPU/RAM/SSD·OS, 캐시 상태, 측정 경계를 증거에 남긴다. 실제 건강 자료·계정·비밀은 사용하지 않는다. 로컬/사설 LLM 서버는 별도 적격 프로필이며 지연/자원 제외 사실을 표시한다.

CLI/분석은 사전 준비 5회 후 측정 20회를 각각 프로세스 시작/종료 또는 아래 명시한 경계로 단조 시계 측정한다. p95는 오름차순 20개 중 **19번째**다. 준비 실행·실패·타임아웃 건수도 보고하고 정상 기대 시험에서 실패가 하나라도 있으면 p95만으로 합격시키지 않는다. 첫 실행/빈 캐시는 별도 5회 모두 보고하며 준비된 결과에 합치지 않는다. 첫 실행에 별도 시간 합격 수치를 만들지 않는다. 메모리는 준비·측정·첫 실행·두 목적 동시 실행 전 구간을 포함한다.

## 지연 예산의 적용

최초 포함 3회 상한·사전 영속 예약·기간별 공통 예산·Retry-After·미확인 비용 처리의 정의는 [복구 요구사항](reliability-requirements.md)의 NFR8.9~NFR8.11을 따른다. 요청/재시도/대기/자식 실행은 각각의 한도만 지키는 것으로 충분하지 않고 600초 전체와 종료 정리를 함께 지켜야 한다. 한도 도달·부분 페이지 처리는 성공 커서로 전진하지 않는다. 프로세스 종료는 원격 효과 취소 증거가 아니다.

## 후속 검증과 제한

본 단계는 문서 검사만 수행한다. 실제 하드웨어/로그아웃 실행·RSS 계측·시간 제한·응답 지연·공급자 한도/가격/모델 지원을 측정하지 않았다. 공급자 실제 정책·권한·동의·유료 조건이 더 엄격하면 우선하며 미확보면 관련 프로필 활성화를 보류한다. 상위 문서의 성능 수치 미정은 이번 승인 Q&A의 시험 목표로 상세화되었으며 실제 운영 적격성 확인을 대신하지 않는다.
