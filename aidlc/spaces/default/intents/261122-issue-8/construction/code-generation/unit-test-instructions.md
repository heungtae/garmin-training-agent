## 테스트 실행 환경

Python 3의 `unittest`와 `tests/u1/requirements.txt`에 버전을 명시한 Draft 2020-12 지원 `jsonschema[format]`을 사용합니다. 첫 Red 전에 테스트 환경과 빈 검증 실행을 준비합니다. 메타스키마와 승인 registry 검증 단계는 네트워크 연결 없이 실행합니다.

```bash
python3 -m pip install -r tests/u1/requirements.txt
python3 -m unittest discover -s tests/u1 -p 'test_*.py' -v
```

## 검증 범위

- 스키마, 고정 registry, 합성 계약 사례에 각 5~8개 테스트를 계획합니다. 파라미터화한 전수 검사로 승인 스키마 12개와 등록된 참조를 모두 확인합니다.
- 각 영역에서 실패 테스트를 먼저 실행하고 실패 원인을 기록합니다. 최소 구현 후 성공을 확인하고 정리 후 재실행합니다.
- 승인 계약 요약의 합성 사례를 사용합니다. 정상 사례에서 필드 하나를 바꾸는 방식으로 오류와 경계를 검증합니다. 실제 Garmin 활동·건강 데이터나 인증정보는 사용하지 않습니다.
- registry가 모르는 URI로 조회를 시도하면 테스트에서 실패를 검증합니다. 제품 서비스, DB 및 SDK는 테스트에 연결하지 않습니다.
- 고정 스키마의 구조 적합성과 승인 설계에 명시된 의미 기대값을 별도로 기록합니다. 의미 규범, RFC 8785 전체 적격성, 재시도와 동시성 중 실행되지 않은 범위를 명시합니다.
